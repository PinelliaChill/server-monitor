# 节点瞭望 服务器监控

React + TypeScript + Vite，普通 CSS。数据全部来自浏览器内的模拟，无服务端。

- 在线演示：[打开节点瞭望](https://server-monitor-demo-bigo.workspace-169790.chatgpt.site)
- 安装依赖：`npm ci`
- 开发：`npm run dev -- --port 5173`
- 测试：`npm test`
- 构建：`npm run build`

首屏使用固定数据；每 2 秒，CPU 与内存各自随机增减 -5 至 +5 个百分点，限制在 0 至 100。状态取两者较高值：80 以下正常、80 至 90 以下警告、90 及以上严重。趋势仅保留最近 60 秒的真实模拟采样，最多 31 点。重新加载页面会重置数据。

筛选与排序实时派生；卡片可用鼠标、Enter 或空格展开。展开状态按服务器 ID 保存，多卡可同时展开，暂时被筛除后仍保留。支持减少动态效果偏好。
